Como adicionar listas e acessar de qualquer computador
  1. Clique em Adicionar lista, informe o título e cole o link compartilhado do Google Drive.
  2. Clique em Baixar página atualizada. O arquivo reúne todas as listas.
  3. No seu repositório do GitHub, use Add file → Upload files para enviar o novo index.html à mesma pasta do anterior e confirme em Commit changes. Se o navegador renomeou o download para index (1).html, renomeie-o para index.html antes.
  4. Aguarde a publicação do GitHub Pages. As listas estarão disponíveis no endereço do site.

Adicionar aqui cria um rascunho neste navegador; não altera o site publicado automaticamente. Você só precisa entrar no GitHub para publicar mudanças. Para consultar e imprimir, basta abrir o site.

Vai imprimir? Abra o PDF e use o ícone de impressão do Google Drive.
O arquivo abre em uma nova aba.
